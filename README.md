# My Portfolio

## About

My personal portfolio website, built for the Web Dev 101 Builders Day project. One page, plain HTML and CSS, no JavaScript - dark theme with a royal blue accent, with sections for who I am, what I know, what I have built, where I study, and how to reach me.

**Live site: https://aditya2375.github.io/webdev101-portfolio-submission/**

## Technologies

- HTML
- Tailwind CSS (compiled to a static style.css - the site needs no JavaScript)

## Privacy and hosting

Static HTML and CSS, with no scripts, analytics, accounts, backend or form delivery service. The contact form only opens a draft in a configured mail application; the visitor reviews and sends it there. CSP/referrer metadata, keyboard focus and reduced-motion styles are included. Personal background is existing portfolio copy, not independently reverified by this technical review.
